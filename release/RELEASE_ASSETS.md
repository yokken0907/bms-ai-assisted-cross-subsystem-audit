1. `BMS_TECHNOLOGY_AUDIT_MASTER_OF_ALL_v1.0.0.zip`

   - Complete archival integration of BMSA-01 through BMSA-14.

2. `BMS_AI_ASSISTED_CROSS_SUBSYSTEM_AUDIT_PUBLICATION_SET_v1.1.zip`
   - SHA-256: `5f783e651f3e64e2063a28c9bfc9337d7978f4421eee738290d01fa58fe47279`
   - Main manuscript + Supplement A/B/C.

The exact upstream source can be downloaded from codeload and is independently hash-checked; it need not be duplicated as a release asset.

## Checksum sidecars

The repository also records conventional `<sha256>  <filename>` sidecars for both recommended release assets. These sidecars describe the canonical release identities; verify the actual downloaded asset bytes before publishing.
