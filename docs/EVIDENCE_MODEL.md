# Evidence model

The publication distinguishes evidence levels rather than escalating a local software observation directly to a product claim.

1. Fixed public source identity.
2. Exact source anchors and source-level observations.
3. Static or host-side executable witness reproduction.
4. Cross-case reconciliation and mapped technical patterns.
5. Explicit limits on deployment, hardware, field, safety, certification, and legal inference.

A witness success is not evidence of physical reachability. A mapped mitigation pattern is not evidence that the exact audited route is effectively mitigated. Failure to establish a candidate-specific mitigation is not evidence that no mitigation exists.
